The story, in words

  1. Open the lid. A Mac opens and a terminal runs arp -a, which lists the IP and MAC pairs the Mac has learned on the lab network.
  2. Windows open and close. Wireshark shows the TCP handshake and the HTTP request from Lab #1, and the UFW rules from Lab #2 decide whether that request gets through.
  3. Take it apart. The display, camera, keyboard, logic board, network chip and battery float apart. The picture is a stylised illustration, not the exact internals of any Mac.
  4. Down to the lens. The camera module separates into cover glass, lens elements and the image sensor.
  5. The network chip. It sends an ARP request to the whole network (a broadcast): who has 192.168.64.1? The owner answers directly (a unicast reply). This is Lab #4.
  6. The lesson. ARP has no authentication, which makes ARP spoofing and man-in-the-middle attacks possible. Read the Lab #4 notes.
